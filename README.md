# SolarCare - Professional Solar Maintenance & Service

A clean, modern landing page for SolarCare — a professional solar maintenance and service platform that helps residential and commercial solar owners keep their systems clean, safe, and performing efficiently.

**Live Version:** [View Website](https://kidswebstorieskids-stack.github.io/solar-care-web/)

![SolarCare Website Screenshot](preview.png)

## Features

- **Single-File Design:** Everything is in `index.html` (HTML + CSS + embedded base64 images). No external dependencies except Google Fonts (Inter).
- **Fully Responsive:** Looks great on desktop, tablet, and mobile.
- **Modern UI:** Clean, professional aesthetic with a green (#008543) brand accent.
- **All Content Included:** Hero, Stats, 14 Service Cards, 9-Step Process, About Section, CTA Banner, and Footer.
- **Real Content:** No dummy text or placeholder images — uses actual company details and assets.

## Sections

1. **Navigation:** Sticky header with logo and call-to-action button.
2. **Hero Section:** Bold headline, tagline, and action buttons over a hero background image.
3. **Stats Bar:** Key metrics (100+ MW Managed, 5+ Years Experience, etc.).
4. **Services Grid:** 14 detailed service cards (Cleaning, SCADA, Maintenance, etc.).
5. **How It Works:** 9-step process explaining the workflow.
6. **About Us:** Company description and key value propositions.
7. **Call to Action:** Green banner encouraging users to book a site visit.
8. **Footer:** Contact information, quick links, and branding.

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/kidswebstorieskids-stack/solar-care-web.git
   ```
2. Open `index.html` in any modern web browser.

*No server or build tools required.*
